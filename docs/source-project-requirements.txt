# PROJECT OVERVIEW

Ruwi is an AI-powered interactive museum platform that transforms traditional museum visits into immersive, personalized learning experiences.

Visitors capture or upload an image of a museum artifact. The platform analyzes the image using Vision AI, identifies the artifact, retrieves trusted historical and cultural information using Retrieval-Augmented Generation, and generates a personalized interactive experience.

The generated experience may include:

* Interactive storytelling
* Historical timelines
* Audio narration
* Educational quizzes
* Artifact hotspot exploration
* Cultural and historical facts
* Interactive visualizations
* Follow-up conversations about the artifact

Ruwi should initially focus on Saudi Arabian and regional cultural heritage while supporting additional cultures and museum collections through an extensible architecture.

The system must support artifacts such as:

* Archaeological objects
* Ancient tools
* Historical manuscripts
* Traditional clothing
* Traditional musical instruments
* Paintings
* Weapons displayed in historical collections
* Coins
* Pottery
* Jewelry
* Architectural objects
* Cultural and historical items

# CORE USER FLOW

1. The visitor opens the platform.
2. The visitor chooses Arabic or English.
3. The visitor uploads or captures an artifact image.
4. The system validates and securely stores the image.
5. Vision AI analyzes the image.
6. The system identifies possible artifact information.
7. The system displays the identification confidence level.
8. The system retrieves relevant trusted knowledge using RAG.
9. The Experience Planner selects appropriate interactive modules.
10. The system generates a complete artifact experience.
11. The visitor explores the story, timeline, facts, narration, quiz, and hotspots.
12. The visitor asks follow-up questions.
13. The visitor may save the experience to their account.
14. Museum administrators can review, edit, approve, and publish artifact information.

# AI SAFETY AND ACCURACY REQUIREMENTS

The platform must never confidently invent historical information.

Implement the following rules:

* Clearly distinguish verified facts from AI interpretation.
* Display source references for retrieved historical facts.
* Display confidence levels for artifact identification.
* Allow the result “Artifact could not be identified.”
* Do not invent exact dates, creators, materials, locations, or historical events when the evidence is insufficient.
* Use phrases such as “possibly,” “likely,” or “uncertain” when confidence is low.
* Follow-up answers must be grounded in retrieved sources.
* AI responses must include citations or source references.
* Museum administrators must be able to correct or approve generated content.
* Store AI model name, prompt version, generation date, and confidence score.
* Validate structured AI output using Pydantic schemas.
* Retry invalid structured outputs safely.
* Log AI errors without exposing sensitive data.
