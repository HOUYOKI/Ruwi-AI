Ruwi 3D artifact models

Each GLB is generated from the corresponding isolated artifact image in ../artifacts/<id>.png.
The silhouette is extruded into real 3D volume, with the original artifact image mapped to the surface.
The frontend supports replacing any model with an original museum scan/photogrammetry GLB without changing the UI.

Important: these are interactive 3D reconstructions from isolated imagery, not claims of museum-grade photogrammetry scans.
